16-bit Mini RISC Processor – Elevator Control System

Project Overview

This project focuses on the design and implementation of a 16-bit Mini RISC Processor for an Elevator Control System using Verilog HDL.

The processor demonstrates fundamental computer architecture concepts, including instruction execution, datapath design, control logic, and digital hardware implementation.

Objectives

- Design a 16-bit RISC processor.
- Understand processor architecture and datapath operation.
- Implement instruction execution using Verilog HDL.
- Explore digital system design and simulation.

Technologies Used

- Verilog HDL
- Digital Electronics
- Computer Architecture
- ModelSim / compatible Verilog simulator

Main Components

- Program Counter (PC)
- Instruction Memory
- Register File
- Arithmetic Logic Unit (ALU)
- Control Unit
- Multiplexers
- Data Memory

Project Application

An elevator control system used as an application to demonstrate processor-based control operations.

Learning Outcomes

- Understanding RISC processor architecture.
- Verilog hardware description and simulation.
- Datapath and control unit design.
- Digital system implementation.
